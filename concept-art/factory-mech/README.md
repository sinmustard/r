# 《공장장》 공장 로봇 콘셉트 아트

쓰레기 처리공장이 거대 로봇으로 변신한 모습이다. 톱니 지붕과 굴뚝, 차량용 셔터는 변신 후에도 남아 있다. 한쪽 팔은 크레인 집게로 적을 잡고 던지며, 다른 팔의 배출관은 오염 폐수를 뿜는다. 청소 로봇은 가슴의 셔터에서 출격한다.

| [정면 픽셀 아트](front-study.png) | 지붕, 셔터, 집게와 배출관을 단순화한 초기 외형이다. |
| [탑다운 대기 자세](top-down-idle.png) | 지붕을 크게 보여 주는 탑다운 시점으로 조정했다. |

## 모션

- [보행 초안](walk-study.png) — 화면 아래를 바라보며 두 발을 번갈아 내딛는 4프레임이다.
- [스킬 모션 초안](skill-study.png) — 위에서부터 청소 로봇 사출, 오염 폐수 방출, 집게팔, 고철 압축, 압축 지뢰, 청소 가속화, 오버클럭 순이다. 각 줄에 동작의 주요 자세 3개를 담았다.

모든 이미지는 콘셉트 아트다. 게임용으로 적용할 때는 프레임 크기와 중심점을 맞춰야 한다.
