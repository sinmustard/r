# 폐수 방출 게이지

- 폐수 방출은 전용 게이지를 사용한다. 전투 프로토타입은 게이지가 가득 찬 상태로 시작한다.
- 게이지가 남아 있을 때 `2`를 누르면 발사하고, 다시 누르면 멈춘다.
- 발사 중에는 마우스로 방향을 바꿀 수 있다. 범위 안의 적은 지속 피해를 받는다.
- 게이지가 가득 차면 최대 **3초** 동안 발사한다. 발사할 때 게이지를 소모하며, 바닥나면 자동으로 멈춘다.
- 발사하지 않을 때 게이지가 천천히 찬다. 빈 상태에서 완전히 차는 데 **15초**가 걸린다. 일부만 차도 다시 발사할 수 있다.
- 별도의 발사 쿨타임은 없다. 전투 화면에 폐수 게이지를 표시한다.

현재 수치는 로컬 전투 프로토타입 기준이다. 발사 중지, 게이지 소모와 재충전은 시뮬레이션으로 확인했다.
